# وثيقة النظام البصري وتصميم تجربة المستخدم (UI/UX Design System)
## منصة دوليان (Dolean) - تصميم موجه للموبايل وتجربة ثنائية المسار (Mobile-First & Dual Intent)

---

## 1. الفلسفة التصميمية وتجربة المستخدم (Core UX Philosophy)

استناداً إلى معايير **`product-ux-design-system`** وبناءً على طبيعة جمهور منصة دوليان (الشباب، طالبي العمل، والباحثين عن تدريب مهني عبر هواتفهم الذكية):

### 1.1 المبادئ الأساسية:
1. **الأولوية المطلقة للموبايل (Mobile-First Ergonomics):**
   - تصميم الواجهة بحيث تكون كافة الأزرار وعناصر الإدخال ضمن **منطقة الإبهام (Thumb-Zone)**.
   - أهداف اللمس (Touch Targets) لا تقل عن `48x48px` لسهولة الضغط أثناء الحركة.
   - تجنب أي تمرير أفقي غير مقصود (Zero Horizontal Overflow).
2. **معالجة ثنائية القصد للمستخدم (Dual-Intent Architecture):**
   - **المسار الأول (أولوية عالية - High Priority):** مستخدم يعرف تماماً ما يحتاجه ولا يريد تضييع الوقت في البحث؛ يجد في صدارة الصفحة بطاقة تفاعلية سريعة: *"اطلب دورتك التدريبية واخبرنا عن مهاراتك"* لربطه فوراً بالفرص.
   - **المسار الثاني (استكشافي - Discovery):** مستخدم يريد تصفح ما هو متاح حالياً من دورات الجمعيات والمراكز (مثل جمعية سنبلة)؛ يجد في متناول يده فلاتر سريعة بنقرة واحدة (مجانية 100%، بدل مواصلات، أونلاين، موقع محدد).
3. **التصميم الهادف ومكافحة الحشو (Anti-Bloat & Purposeful Design):**
   - حذف أي عناصر تزيينية لا تخدم هدف المستخدم المباشر.
   - نصوص UX واضحة، مباشرة، وباللغة العربية الفصحى الطبيعية دون ترجمة حرفية أو كلام تسويقي فارغ.
   - دعم كامل للاتجاه من اليمين إلى اليسار (Arabic RTL).

## 2. لوحة الألوان والخطوط (Visual Identity & Design Tokens)

### 2.1 لوحة الألوان المعتمدة (Harmonious Color Palette):

| اللون | القيمة السداسية (Hex) | الاستخدام الدلالي |
| :--- | :--- | :--- |
| **الأزرق الملكي (Electric Sapphire)** | `#2563EB` / `#1D4ED8` | اللون الأساسي للمنصة (Primary)، الأزرار الرئيسية، الهوية، الثقة والمهنية. |
| **الأخضر الزمردي (Emerald Opportunity)** | `#10B981` / `#059669` | شارات الدورات المجانية (100% Free)، بدلات المواصلات المؤمّنة، وإشارات النجاح والتأكيد. |
| **الكحلي العميق (Deep Navy Slate)** | `#0F172A` / `#1E293B` | العناوين الرئيسية، النصوص البارزة، والأسطح ذات التباين المرتفع. |
| **رمادي ناعم (Clean Surface)** | `#F8FAFC` / `#F1F5F9` | خلفيات البطاقات وحقول الإدخال النظيفة المريحة للعين. |
| **أزرق سماوي خفيف (Soft Ice Blue)** | `#EFF6FF` / `#DBEAFE` | خلفيات الشارات والوسوم (Pills & Badges). |

### 2.2 التيبوغرافيا والخطوط (Arabic Typography):
- استخدام خط عربي عصري هندسي ومقروء على شاشات الجوال الصغيرة (مثل **Lama Sans** المتوفر حالياً في أصول المشروع، أو **Readex Pro** / **Cairo**).
- أوزان واضحة: `font-bold` (700) للعناوين، و `font-medium` (500) للنصوص والتفاصيل، مما يحقق هرمية بصرية فورية (Visual Hierarchy).

## 3. تفاصيل مكونات الواجهة المطورة (Component Blueprint)

### 3.1 الهيدر العصري المحدث (Modern Frosted-Glass Header):
* **المشكلة السابقة:** الهيدر القديم كان يحتوي على مسارات SVG معقدة وقديمة وشريط تنقل تقليدي لا يتناسب مع الموبايل.
* **الحل الجديد:**
  - هيدر عائم أنيق بخلفية زجاجية شبه شفافة (`backdrop-blur-md bg-white/85`).
  - شعار "دوليان" الحديث بخط عربي رشيق وأنيق.
  - زر نداء لاتخاذ إجراء واضح (CTA): "اطلب دورتك" أو زر الحساب الدائري السريع.
  - قائمة موبايل منبثقة بسلاسة وداعمة للمس.

### 3.2 بطاقة الطلب السريع (Quick Course Request Hero Card):
* تظهر في مقدمة الصفحة الرئيسية ومحسنة للموبايل:
  - حقل إدخال ذكي: *"اكتب اسم الدورة أو المهارة التي تبحث عنها..."*
  - وسوم سريعة بنقرة واحدة (برمجة، تسويق، تصميم، لغات، إدارة).
  - زر تفاعلي عريض: *"سجل رغبتك الآن"* ينقل المستخدم إلى خطوة التأكيد في ثوانٍ.

### 3.3 شريط الفلاتر السريعة الأفقي (Horizontal Swipeable Filter Bar):
* مخصص لشاشات اللمس (Touch-scrollable):
  - 🟢 `مجانية 100%`
  - 🚌 `بدل مواصلات مؤمن`
  - 💻 `تدريب عن بعد (أونلاين)`
  - 📍 `المدينة (بيروت، طرابلس، صيدا، دمشق، إدلب...)`
  - 🎓 `شهادة معتمدة`

### 3.4 بطاقات الدورات المطورة (Modern Course Cards):
* صورة واضحة بنسبة أبعاد مدروسة.
* شارة اسم الجهة المنظمة للتدريب (مثال: **جمعية سنبلة**).
* شارة السعر وبدل المواصلات بلون أخضر مريح ومحفز.
* رمز الحفظ / المفضلة السريع.
